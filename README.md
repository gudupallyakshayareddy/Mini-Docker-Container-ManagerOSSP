# Mini Docker Container Manager

A lightweight command-line container manager developed for the Operating Systems and Systems Programming project.

## Review 1

- Interactive REPL loop
- Basic command parsing
- GitHub repository structure
- Makefile-based compilation
- C implementation

## Commands

```text
help
create <name>
start <name>
stop <name>
list
exit
```

## Build

```bash
make
```

## Run

```bash
make run
```

## Clean

```bash
make clean
```
